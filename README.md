# KOSAT

LSAT trivia from the Kos games. Spin the wheel or play the board across five LSAT question types (Assumptions, Strengthen & Weaken, Flaws, Inference, Reading Comp) plus Objection!, a just-for-fun law trivia category.

All questions are original LSAT-style practice questions, not official LSAC questions. Every answer shows an explanation.

Play: open `index.html` in a browser, or turn on GitHub Pages for this repository.
